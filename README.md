# ОГЭ-2027: обществознание

Интерактивный курс подготовки к ОГЭ по обществознанию по модели 2027 года (20 заданий, 32 балла).

Открыть курс: https://maxkrivachev-web.github.io/oge-kurs/

- 13 модулей: экзамен, темы кодификатора, практикумы, пробники
- карта всех 20 заданий, расписание, словарь определений
- мини-тесты с проверкой и ссылки на тренировку в Решу ОГЭ
- прогресс сохраняется в браузере; на странице «Прогресс» его можно перенести на другое устройство кодом

Весь курс - один файл `index.html`. Чтобы обновить курс, замени этот файл: прогресс у читателей сохранится, пока адрес сайта тот же.
