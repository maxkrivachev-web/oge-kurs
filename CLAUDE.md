# Правила проекта: курс ОГЭ-2027 по обществознанию

- Курс - один файл `index.html`, собирается из `src/` командой `python3 src/build.py`. Других внешних зависимостей, кроме Golos Text из Google Fonts, не добавлять.
- Текст только на русском. Только обычный дефис «-», без длинных и средних тире (сборка их ловит). Без эмодзи. Кавычки «ёлочки».
- Не менять ключ `oge27-soc-v1` и атрибуты `data-k` у отметок: на них прогресс читательницы. Новые данные - только под новыми ключами `oge27-*`, и добавлять их в `ALLKEYS` в шаблоне, чтобы они попали в код переноса.
- Источники по уровням: ФИПИ и нормативные акты (L1) выше сборников (L2), сборники выше школ и СМИ (L3). Расхождения записывать в `AUDIT.md`. Непроверенное - в раздел «Требует проверки».
- Учебник под ред. Д.А. Медведева (2026) не копировать абзацами: пересказ своими словами и номер параграфа. Сам PDF и извлеченный текст в репозиторий не класть.
- Задания: авторские помечать «авторское задание по модели ФИПИ», из банка - «задание банка ФИПИ, подходит к линии N». Каждое задание решать самостоятельно; спорные не включать.
- Верстка только через компоненты из `DESIGN.md`. Красный цвет только для ловушек.
- Две копии: GitHub Pages и артефакт claude.ai. После каждого крупного этапа обновлять обе одним и тем же `index.html` и сверять хеш.
- Перед публикацией: `python3 tools/ui_check.py index.html` и `python3 tools/interact_check.py` без ошибок.
- Ход работы и что осталось - в `AUDIT.md`, раздел 0.
